### Step 3: Link to your GitHub Repository
```bash

git remote add origin https://github.com/kanna857/Kanna857.git
```
*(If the remote already exists, update it with `git remote set-url origin https://github.com/kanna857/Kanna857.git`)*

### Step 4: Push to Main Branch
```bash
git push -u origin main --force
```

## 🐍 Enabling the Contribution Snake

1. Once pushed, navigate to your repository on GitHub:  
   `https://github.com/kanna857/Kanna857`
2. Go to **Settings** → **Actions** → **General**.
3. Under **Workflow permissions**, select:
   - **Read and write permissions**
   - Check **Allow GitHub Actions to create and approve pull requests**.
4. Click **Save**.
5. Navigate to the **Actions** tab in your repository.
6. Select **Generate Contribution Snake** on the left menu.
7. Click **Run workflow** → **Branch: main** → **Run workflow**.
8. Once the workflow completes, it creates an `output` branch containing the snake animation SVGs, and your README will instantly display your animated snake!
