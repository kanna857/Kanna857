# GitHub Profile Setup (No Audio)

1. Extract this ZIP.
2. Open or create the public GitHub repository `kanna857/kanna857`.
3. Upload `README.md`, the `assets` folder, and `.github/workflows/snake.yml`, preserving paths.
4. Commit the changes.
5. Optionally open GitHub Actions and manually run the contribution snake workflow.
6. Visit https://github.com/kanna857 to view your profile.

This package contains **no audio, music player, or music links**. The Krishna imagery, animated petals, heading, and devotional illustrations remain.
